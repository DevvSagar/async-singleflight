**Production-grade SingleFlight & request coalescing engine for Python asyncio and FastAPI.**

Prevents **Cache Stampedes (The Thundering Herd)** by suppressing duplicate concurrent calls to slow databases or downstream microservices.

---

## 1. What Problems It Solves

- **The Cache Stampede (Thundering Herd)**: When a cache expires under high traffic, hundreds or thousands of simultaneous requests encounter a cache miss and execute the exact same heavy database query at the exact same millisecond.
- **Database Connection Pool Exhaustion**: Databases have finite connection limits. A sudden traffic surge hitting an uncached route exhausts connections, causing cascading 500/504 errors across the entire application.
- **Redundant Work & Wasted Cloud Spend**: Computing identical expensive aggregations 1,000 times concurrently wastes database CPU and memory without delivering any extra value to users.

---

## 2. Where It Solves It

`async-singleflight` runs **in-process at the application layer** (inside FastAPI or your service layer), intercepting calls before they reach your database or downstream APIs:

- **E-Commerce Flash Sales**: Thousands of users refreshing the same high-demand product page.
- **Trending Feeds & Leaderboards**: Millions of users loading identical top-ranking lists.
- **Financial Dashboards**: Heavy analytical queries aggregating stock/crypto market data.
- **AI & External APIs**: Deduplicating expensive third-party API calls generated by simultaneous user actions.

---

## 3. Tech Stack

- **Core Engine**: Python 3.11+, native `asyncio` primitives (`Future`, `Lock`, `shield`).
- **Web & Middleware**: FastAPI & Starlette (ASGI pipeline integration).
- **Database**: PostgreSQL with `asyncpg` & SQLAlchemy 2.0 (demonstrating connection pool protection).
- **Load Testing & Proof**: Locust & HTTPX (simulating flash-crowd bursts).
- **Packaging & DevOps**: Modern `pyproject.toml` standard + Docker Compose for 1-command reproduction.

---

## 4. How To Use It (High-Level)

1. **As a Function Decorator**: Wrap any slow database query or service function with the protection decorator. All simultaneous calls with matching arguments automatically share one execution.
2. **As an ASGI Middleware**: Attach the middleware to your FastAPI app to automatically intercept duplicate HTTP GET requests at the route level.
3. **As a Direct Coordinator**: Call the coordinator directly with a unique key whenever you need low-level programmatic control in background tasks.
